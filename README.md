# 🌞 Solar Manager - G02 DAM1

## 🔹 Descripción

**Solar Manager** es una herramienta integral para empresas instaladoras de sistemas fotovoltaicos. Permite centralizar la gestión comercial y el diseño técnico en una plataforma unificada, reemplazando procesos fragmentados por un flujo de trabajo más eficiente.

Desde la toma de datos inicial hasta la generación de presupuestos profesionales, la aplicación automatiza cálculos, organiza la información del cliente y mejora la coordinación entre equipos comerciales y técnicos.

---

## ⚙️ Funcionalidades principales

### 📌 CRM y gestión comercial
Seguimiento de visitas, presupuestos, materiales y estados del proceso.

### 📐 Dimensionamiento técnico
Cálculos automáticos basados en consumos, orientación y localización del inmueble.

### 📄 Documentación profesional
Generación de PDFs con firma y validación de datos.

### 👥 Gestión de clientes
Registro completo de datos del cliente y su instalación.

### 🔐 Control de acceso
Roles y permisos diferenciados según perfil de usuario.

### 📱 Movilidad futura
Extensión prevista a Android para trabajar en campo con información sincronizada.

---

## 🛠 Tecnologías

- **Java 17** – Aplicación de escritorio  
- **JavaFX 17** – Interfaz gráfica  
- **MongoDB 4.4** – Base de datos NoSQL flexible y escalable  
- **Android Studio (futuro)** – App móvil para acceso en campo
